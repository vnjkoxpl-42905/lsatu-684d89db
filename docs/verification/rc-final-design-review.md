## Acceptance criteria
- Passage-focused singular/plural heading, main Choose for me / Pick passages, compact auto count, timing including custom, Show answers.
- Manual mode uses actual selected count and Edit selection, no disabled automatic stepper.
- Applied passage filter summary beside Customize drill; no repeated timing/reveal/mode information.
- Review your selection before starting beside primary Preview drill.
- Customize drawer has passage filters only, including source/format/framework/multiple difficulty/status/PrepTest controls. No duplicated mode/reveal controls. Existing question-family/type/feature search is a separate /rc/search destination, not an invented inline passage filter.
- Same drawer system provides manual search, selection, selected-list ordering, remove and clear controls. Apply commits draft mode and selections; close/Cancel/Escape/backdrop discard draft. Inactive drafts retained only as applied state; applied main remains unchanged while editing.
- Preview respects current applied selection and order, reports fixture shortfall, never simulates real adaptive history, launch, recording or saving.
- Keyboard containment, inert background, return focus, visible focus, touch targets, narrow widths, scrollable preview, reduced motion, no inaccessible animation-dependent content.
- Three actual design iterations documented with findings, changes and evidence, not three screenshots of identical code.
