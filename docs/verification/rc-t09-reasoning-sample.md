## Confirmed reasoning defects repaired in owned files

Only authored summaries, explanation bodies and explanatory tags were edited. Source passage text, prompts, answer choices, keys, source IDs, ordering and statistics were preserved.

- **PT101 / 1188:** Q7660 treated the presence of a solution as automatically determining the main point and rejected E merely for failing to mention risk communicators. Replaced those shortcuts with the author's overall recommendation and E's misdescription of ethical concerns. Corrected Q7664 E's purported quotation from experts' “decisions” to “definitions.” Summary qualifiers now preserve “many” lay people and “reasonable estimates”; a differently prepared government brochure is not described as certainly lacking preparation.
- **PT110 / 1034:** Q5355 A omitted the offspring condition and treated the ordinary development of an organ as identical to inherited development. E incorrectly explained vertical inheritance through the exact genes a parent possessed at birth. Q5358 E invented a specific selective-breeding cause for aggression. Q5359 B equated accelerated evolution with an accelerated process of natural selection. Replacements distinguish inheritance from ordinary development, environmental acquisition from ancestry, and evolutionary speed from explaining natural selection.
- **PT120 / 776:** The summary confused virulence with contagiousness, suggested a bedridden host necessarily dies, and switched from pathogen to virus without support. Rewrote it from the passage's transmission-versus-loss comparison, preserving both vector transmission and survival outside a host. Q6699 D previously compared replication rates with host-killing rates, which is not the source comparison. Q6697 D needlessly required a vector, overlooking sit-and-wait transmission. Q6703 B now uses the actual hours-versus-weeks-or-months evidence instead of outside speculation about air and surfaces.
- **PT125 / 483:** Q3031 E printed the same conditional twice and reversed “only during.” Corrected it to release implies drilling phase; drilling does not imply continuous release. Q3032 E falsely said A never mentioned cuttings, which appear in A's first paragraph. Q3033 C falsely attributed food and medical uses of barite to B; corrected to A. Q3035 B's “opposite” tag implied an unsupported bentonite comparison; changed it to unsupported comparison.

- **PT132 / 343:** Q1734 reduced the fiber/grit argument to “more wear, fewer caries” and missed the severe-wear exception that exposes the pulp cavity. Rebuilt the support window using both effects. ## Validation and limits

A recursive JSON comparison against HEAD checked every changed leaf in the eleven owned bank files: changes were confined to summaries, explanation blocks, choice explanations and explanatory tags. All source and assessment fields remained identical. JSON parsing succeeded for the edited files. The parent release run owns application build, bank integration tests, and browser rendering verification.

The content is generally strongest when it names the actual source detail and explains the exact mismatch. Recurring defects are dropped qualifiers, false absence claims, conflating theories with their subjects, and using “best available” as a substitute for explaining textual support. This review repairs confirmed instances in the sample. It does not certify all 320 passages, all 2,150 questions, or the missing-prose backlog, and it is not a learner-outcome or copyright review.
