## Authorized remediation design and acceptance
1. Explicit boundary intent: export notifyClassroomListIntent(element, intent) where intent is filter, restore or paginate. Every mounted hook registers its root/handler in a module WeakMap; helper walks element.parentElement ancestors and calls only the first registered owner. Registration covers reduced-motion with a no-op handler and is cleaned on unmount; no bubbling event or class-only resolution. Notes update(q/filter/type), Clear filters and MyWork updateFilter/Clear filters call filter synchronously before state updates; portaled menu callbacks use the page/section ref. Filter settles current list records/queued/pending entries and suppresses entrants until an explicit pointer paginate action. This is not permanent for the boundary: pointer Load more calls paginate before updating shown, clearing filter suppression for newly discovered rows; keyboard/input sticky settlement remains immediate. Keyboard Load more does not re-enable animation. Restore intent settles current and subsequently loaded rows until pagination. Tests cover pointer Unread/type -> Load more, newly surfaced filter identities and nested owners (inner only, outer unchanged).
2. One list-entry batch scheduler for initially visible, async visible, paginated and offscreen entering list rows. All list tweens start paused; immediately visible rows join the same frame queue rather than use per-group cumulative indices. Sort entering batch by DOM reading order across month/status groups, distribute distinct delays with step=min(.05,.15/max(1,batchlength-1)), restart(true),240ms/y8/opacity preset. ScrollTrigger remains attached to actual scroller for below-fold rows. All queued callbacks, tweens and triggers are scoped/cleaned; focus settlement removes queued entries. Preserve default non-list caps/preset and global active-runner/readiness gates.
3. Return intent: before archive anchor focus/scroll restoration, signal the same owning boundary to settle every list row and mark future loaded rows immediate. Do not change account/path scoped storage, nearest survivor, reader/read-state mutation or smooth-return modality rules. Normal focusin to a single row alone need not disable every future reveal; restoration uses explicit intent.
4. Domain filter validity: Subject whitelist lr/rc/mixed/unknown and known work-type labels are independent of current loaded rows. Preserve existing label-valued kind URLs for compatibility in this bounded fix; no display-label/key migration needed. Active valid values remain selectable even if absent from visible rows, and controls/Clear filters remain available when the active valid filter yields no rows. Invalid URL values fail open as before. Access filtering happens before matching/counting; no hidden source metadata or options inferred from unauthorized rows. A valid but absent domain option indicates selected intent, not existence of unauthorized assignments. Partial feed loads may show empty matched results but must never show unrelated rows or silently discard valid selection. No feed loading-contract changes.
5. Explicit My Work content policy: StudentDestination marks its My Work content wrapper data-motion-policy="list-only" (other destinations unchanged). The shared hook excludes the policy wrapper and all its non-list descendants from candidate animation and generic fallback descent, while still discovering explicit items inside nested data-motion-list groups. Merely removing data-motion-enter is insufficient: generic fallback could descend and animate children. Only after the policy is present remove redundant item/ready markers on role=status loading paragraphs and the outer work section. The existing loading markers currently prevent parent selection, so remove them as an atomic policy change, not as a harmless isolated cleanup. My Work headings remain under their existing separate local boundary; the no-blur/no-travel assertions apply to My Work content states, not that unchanged heading. Policy composition tests include assigned loading/error/empty/no-match, notes loading/error/empty and Personal notes, and ensure a non-My-Work wrapper still uses its default entrance. No data-motion-skip ancestor that would exclude descendant lists.
