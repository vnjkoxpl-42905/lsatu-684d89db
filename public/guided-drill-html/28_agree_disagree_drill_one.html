Timed Set

TYPE: Agree / Disagree
LENGTH: 8 q's, 12 mins (1.5x = 18, 2x = 24)
TESTS: 65, 71, J07
LEVEL: 2, 3, 4

Try these problems under timed conditions, selecting answers, but not confirming them. Once the timer goes off, go back through the questions untimed to finalize your thinking before confirming your answers.

Process
Read

Read each person's statements
(don't worry about finding conclusion vs. support)

Revisit

After you've read each person's paragraph, go back and revisit each claim the 1st person made.

Classify

For each claim, ask yourself if the 2nd person agreed / disagreed / we don't know.

Assumption

If there aren't any explicit claims that the 2nd person is agreeing / disagreeing with, then ask yourself whether the 1st person is assuming anything the 2nd person would agree/disagree with.
