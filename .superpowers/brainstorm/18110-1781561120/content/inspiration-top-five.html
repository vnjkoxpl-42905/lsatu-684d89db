Reference Set · Teacher Workspace

Top five inspiration pools to use.

These are not sites to copy. Each has a job: real product patterns, premium dark styling, futuristic composition, or broad visual search. We will combine them into one LSAT U-specific direction.

01

Refero

Real product UI references

Use it for task rows, sidebars, filters, empty states, memory/settings surfaces, and real app workflows.

  • Borrow: pattern quality, dense-but-clear product screens.
  • Avoid: turning Today into a generic SaaS dashboard.
Primary product reference
02

Mobbin

Production flow library

Use it to study how real apps handle list-detail workflows, action review, approvals, and navigation hierarchy.

  • Borrow: flows and interaction logic.
  • Avoid: consumer-app softness that weakens the teacher operator feel.
Workflow reference
03

Godly

Futuristic web taste

Use it for premium composition, spacing, dark surfaces, and memorable visual posture.

  • Borrow: atmosphere and high-end visual discipline.
  • Avoid: portfolio effects that hurt utility.
Mood reference
04

Dark.Design

Premium dark mode

Use it for the OLED, minimal, futuristic dark palette without making the interface feel noisy or neon.

  • Borrow: restraint, contrast, dark hierarchy.
  • Avoid: low-contrast gray-on-black fatigue.
Visual system reference
05

Pinterest

Wide mood-board search

Use it only to collect broad “futuristic dashboard” and “teacher dashboard” mood cues, then filter aggressively.

  • Borrow: visual motifs and layout sparks.
  • Avoid: concept art, fake widgets, and overdesigned sci-fi panels.
Broad search reference
Recommended use: Refero + Mobbin decide the product anatomy. Godly + Dark.Design decide the premium futuristic feel. Pinterest is only a broad mood-board source, not the authority.
