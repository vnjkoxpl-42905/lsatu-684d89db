# Matching Keywords Framework

**Synopsis**
A two-step framework for Role, Method, and Flaw answer choices. Read the structure first, then check every keyword.

> **IDENTIFY (S)TRUCTURE → (K)EYWORDS**

**(S) Structure**
Hold a clear grasp of the premises, conclusions, and assumptions in the argument before reading the answers.

**(K) Keywords**
Know what each keyword in the answer choice means. Do not choose an answer if you cannot match its keywords to the stimulus.

**How To Guide (6 steps)**
1. Read the answer choice over. Extract any keywords that stand out.
2. Analyze each keyword in LSAT context, not daily-English context.
3. Check keyword relevance:
   - Noun: does this concept appear in the stimulus?
   - Verb: does the author do this in the argument?
   - Adjective or adverb: does it correctly describe the tone or strength of the author's argument?
4. Match the answer choice against the stimulus structure.
5. Go back and forth between answer choice and stimulus. Practice makes this fast.
6. Beware of traps. The test often provides an almost-perfect answer ruined by a single word, sitting next to a correct answer that reads vague.

**Watchful Eye, Deviations, Question Types**
- Watchful Eye: read answer choices carefully to ensure they accurately reflect the argument.
- Deviations: eliminate choices that describe events or actions not present in the stimulus.
- Question Types: especially useful for Role, Method, and Flaw. Strengthen/Weaken correct answers often introduce new elements not directly stated.
