# The Verb Taxonomy

**Synopsis**
LSAT verbs are not interchangeable. Each carries a specific structural implication.

| Verb family | What it means structurally |
|---|---|
| Concludes / Infers / Reasons / Argues | Author has a conclusion |
| Presupposes / Assumes / Takes for granted | Author depends on something unstated |
| Appeals to / Cites / Uses / Invokes | Author is invoking evidence |
| Counters / Anticipates / Pre-empts | Author shuts down an objection in advance |
| Denies / Rejects / Challenges | Author argues against another claim |
| Substantiates / Supports | Provides evidence for something |
| Establishes / Demonstrates | Stronger: provides proving evidence |
| Undermines / Weakens / Calls into question | Author attacks another claim |
| Illustrates | Author is giving an example |
| Derives | Author concludes something from a constraint |
| Maintains / Holds / Contends | Author has a position (often opposing view) |
| Posits | Author proposes something, usually a causal account |

**How to use**
Identify the verb in the answer choice first. The verb tells you what move the author is making. Then check whether the stimulus actually shows that move.
