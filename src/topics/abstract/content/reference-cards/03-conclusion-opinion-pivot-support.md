# The Conclusion-Opinion-Pivot-Support Schema

**Synopsis**
Every clause in an LR stimulus is one of four things. Label them.

**The four buckets**
- **Conclusion.** A claim being made.
- **Opinion.** A value judgment, prediction, or recommendation. Almost always lives inside a Conclusion slot.
- **Pivot.** A switch in viewpoint.
- **Support.** A reason or evidence.

**How to use**
1. Underline every clause.
2. Label each with one of the four buckets.
3. Group adjacent same-bucket clauses.
4. The Conclusion bucket usually contains the slot you care about.
