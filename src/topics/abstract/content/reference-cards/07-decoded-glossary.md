# The Decoded Glossary

**Synopsis**
The LSAT vocabulary you need to know cold. Definitions are LSAT-specific, not dictionary-general.

| Term | Means on the LSAT |
|---|---|
| **Inference** | A claim that must be true given the statements. Provable, not necessarily important. |
| **Imply / Suggest** | Indicate or hint at, but weaker than entail. |
| **Entail** | Logically guarantee. |
| **Presuppose** | Require. A necessary condition. |
| **Assume / Take for granted** | Rely on without proof. |
| **Explanation** | Cause. |
| **Hypothesis** | Potential cause. A causal guess. |
| **Phenomenon** | Something that happened that needs explaining. The effect side. |
| **Illustrate** | Give an example of. |
| **Analogy** | A different specific case that's similar in some general way. |
| **Example** | A specific case that illustrates a general idea. |
| **Counterexample** | A specific case that goes against a general claim. |
| **Alternate Explanation** | A different proposed cause for the same effect. |
| **General Principle** | A rule that applies to multiple scenarios. Not just one case. |
| **Generalization** | A summary statement derived from cases. Describes what *is*. |
| **Principle** | A guiding rule. Prescribes what *should* be. |
| **Aesthetic Principle** | A broad normative rule, not a one-off judgment. |
| **Defend** | Justify as right or correct. Not just stating a motive. |
| **Substantiate** | Support with evidence. |
| **Corroborate** | Confirm or back up. |
| **Establish** | Prove. Stronger than support. |
| **Undermine** | Weaken. Attack the support. |
| **Refute** | Prove false. Stronger than undermine. |
| **Concede** | Admit something potentially against your own position. |
| **Maintain / Hold / Contend / Assert** | Claim or argue. Often the verb attached to an opposing view. |
| **Posit** | Propose, usually a cause. |
| **Account For** | Explain. Causal sense. |
| **Decision** | A choice. Can be premise or conclusion. |
| **Fact** | A statement true regardless of viewpoint. Often premise or background. |
| **Supported Premise** | An intermediate conclusion. Functions as both a premise and a sub-conclusion. |
