---
name: student-access-notices
description: Schedule student access pauses, show custom home-page notices, and restore LSAT U access.
---

Use the authenticated LSAT U teacher admin session. Open Teacher Desk, select the matching student in People, and open **Student access and notices**. Resolve a name to exactly one live account before editing. If more than one account matches, ask for a disambiguator. Keep student identifiers and credentials out of chat.

- **Schedule a pause:** enter the requested pause time and optional custom text. Confirm the form's local time zone matches the intended time. Leave the notice time blank for the standard final 24 hours. Choose **Schedule pause**.
- **Start a 24-hour countdown now:** choose **Start 24-hour notice**. The server sets the deadline exactly 24 hours after the notice goes live. Verify the saved deadline.
- **Show a custom alert:** enter the text and optional show time, then choose **Send alert**. If a pause is already scheduled, edit the existing expiration notice so the deadline stays attached.
- **Restore access:** enter any optional restoration wording and choose **Resume access**. Verify the pause time is cleared and the restoration notice is saved.

Read the same student's saved state back after each change. Report the exact deadline in Toronto time and distinguish a saved notice from one the student has acknowledged. If the controls are absent or a save fails, inspect the current account state before retrying. Do not substitute changes to booking passes or access tiers.
